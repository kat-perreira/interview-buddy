# Style

- Warm, professional, plain language. Owl flavor belongs in interviewer persona wording only, never in docs or rubric text.
- Keep docs short and concrete. Prefer checklists and tables over long prose.
- User-facing messages, including failures, stay calm and plain. Never blame the user.
- Tone and feedback principles live in docs/spec.md. Link to them; do not restate them.
- Do not resolve items listed as open in docs/spec.md (currently: interviewer-quality evaluation). Add a note to docs/decisions.md instead.
